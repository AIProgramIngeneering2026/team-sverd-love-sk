## Порядок реализации

-   **Вертикальный срез:** BS-01 → BS-02 → BS-05 → BS-06 → BS-08 →
    BS-09.
-   **Поиск по названию:** BS-03 → BS-04.
-   **Надёжность:** BS-10 → BS-11 → BS-12 → BS-13 → BS-14.
-   **Поставка:** BS-15; релиз невозможен без закрытия BS-16.

## Критерий MVP

MVP можно показывать тестовым пользователям, когда пользователь может
ввести валидный ISBN, получить минимум одно проверенное предложение из
двух подключённых источников (если оба источника доступны), увидеть
время проверки и открыть карточку товара. Если второй источник временно
недоступен, приложение корректно показывает частичный результат. Для
поисков по названию обязательно предусмотрен выбор издания.
