# BookScout --- поиск лучших цен на книги

**BookScout** --- кроссплатформенное desktop-приложение для поиска книги
по ISBN или названию и сравнения предложений российских
интернет-магазинов.

## Проблема

Чтобы купить конкретную книгу выгодно, человеку приходится отдельно
искать её на маркетплейсах и в книжных магазинах, проверять совпадение
издания и сравнивать цены. Результаты поиска часто относятся к разным
изданиям, а самая низкая цена товара не всегда означает самую низкую
итоговую стоимость с доставкой.

BookScout сокращает эту работу: пользователь вводит ISBN или название,
приложение находит подходящую книгу, собирает доступные предложения
подключённых магазинов и показывает цены со ссылками на карточки
товаров.

## Для кого

-   читатели, которые регулярно покупают бумажные книги;
-   родители и студенты, покупающие учебную литературу;
-   люди, которые сравнивают цены перед покупкой и готовы перейти в
    магазин для оформления заказа.

## Что входит в систему

-   desktop-интерфейс: поле поиска, список найденных изданий, таблица
    предложений;
-   поиск книги по ISBN-10/ISBN-13 или текстовому запросу «название +
    автор»;
-   подтверждение выбранного издания, если найдено несколько вариантов;
-   адаптеры источников цен с единым внутренним форматом предложения;
-   нормализация результатов, дедупликация и сортировка по известной
    стоимости;
-   отображение магазина, названия товара, цены, наличия, времени
    проверки и ссылки;
-   локальная база SQLite для кэша и истории последних поисков;
-   журналирование ошибок источников и состояния поисковой задачи (Job).

## Что точно не входит в MVP

-   покупка товара, корзина, оплата и оформление заказа;
-   гарантия наличия товара или фиксации цены после перехода в магазин;
-   учёт персональных скидок, баллов, купонов и динамической цены
    конкретного пользователя;
-   достоверный расчёт доставки для любого адреса и способа получения;
-   мониторинг цены и push/email-уведомления;
-   сканирование штрихкода с камеры, OCR и распознавание обложки;
-   рекомендации, отзывы, рейтинги книг и социальные функции;
-   поддержка всех магазинов России и обход CAPTCHA/антибот-защиты;
-   мобильная и web-версии.

## Принципы MVP

1.  **Сначала точность идентификации.** Предложения разных изданий
    нельзя выдавать как прямое сравнение.
2.  **Прозрачность данных.** Показываем время получения цены и отдельно
    отмечаем неизвестную стоимость доставки.
3.  **Никаких выдуманных предложений.** Если источник недоступен, он
    помечается как не проверенный, а не как магазин без товара.
4.  **Разрешённый доступ к данным.** Для каждого магазина до реализации
    проверяются официальные API, партнёрские фиды и условия
    использования. Не строим MVP на обходе технических ограничений.

## Предлагаемый технологический стек

-   Python 3.12+
-   PySide6 (desktop UI)
-   httpx (HTTP-клиент)
-   SQLAlchemy + SQLite (локальные данные и кэш)
-   pytest (тесты)
-   PyInstaller (сборка desktop-пакета)

Архитектура --- модульный монолит: UI → application services → book
resolver / store adapters → нормализованные модели → SQLite. Сетевые
вызовы выполняются асинхронно или в рабочих потоках, чтобы интерфейс не
зависал.

## Запуск

На этапе MVP команды установки и запуска будут добавлены после создания
каркаса приложения. Предполагаемая команда разработки:

``` bash
python -m venv .venv
pip install -r requirements.txt
python -m app
```

## Статус

Документы описывают целевой MVP и план работ. Доступность API и
легальность конкретного способа получения цен должны быть подтверждены
отдельно до включения магазина в релиз.
